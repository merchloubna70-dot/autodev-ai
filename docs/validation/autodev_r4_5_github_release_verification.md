## Secret Hygiene of release.yml

- Token is passed via **env block** (`TWINE_USERNAME`, `TWINE_PASSWORD`), NOT via CLI `-p` flag. So token never appears in process argv / `/proc/<pid>/cmdline` / shell history.
- GitHub auto-masks any output that contains the secret value (defense in depth).
- The detector step writes only the boolean `has_token=true|false` to `$GITHUB_OUTPUT`, not the token value.

No secret leakage path identified in workflow logs.
